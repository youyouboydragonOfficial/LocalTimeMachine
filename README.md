# ⏳ Local Time Machine (ローカル・タイム・マシン)

> **最強のパソコン用ローカル・タイムトラベル＆安全隔離復元システム**  
> 間違って上書き・完全削除しても安心。ショートカットではなく実体バイナリを専用安全区域（Vault）に二重保管し、過去のあらゆるバージョンへいつでもワンクリック復旧できます。

---

## ⚡ 核心機能・特徴

1. **🚫 ショートカットのみ登録の禁止（完全物理バイナリコピー）**
   - ショートカット（.lnkやシンボリックリンク等）で登録してお茶を濁すことは一切ありません。
   - ファイル実体のバイナリデータを専用安全区域（Safe Vault）に物理複製して保存します。

2. **🛡️ エクスプローラー直接保存の禁止（隔離保護）**
   - ユーザーが通常のWindowsエクスプローラーで誤操作したり、ウイルスや誤作動で巻き込まれないよう、独立した専用安全区域（Safe Vault）に保護・保管します。

3. **⚠️ インストール＆初回起動時の「容量2倍警告」と明確な理由説明**
   - 元のファイルが破損・誤削除・誤上書きされても確実に救出できるよう、実体を二重バックアップ（物理複製）するため、ストレージ容量が約2倍使用されます。この理由と安全性を納得した上で安心してご利用いただけます。

4. **🕒 時間系列（タイムライン）スナップショット表示＆タイムトラベル**
   - 保存されたファイル、高画質写真、動画、文書、ソースコードのスナップショットを直感的なタイムラインスライダーで過去に遡って閲覧・管理できます。

5. **📚 無制限のバージョン世代管理**
   - 同名ファイルが変更されるたびに新しい世代（v1, v2, v3...）として自動記録。
   - SHA-256ハッシュによる厳密な整合性チェックにより、同一内容の重複は防ぎつつ、変更箇所を確実にバージョン管理。

6. **🔄 強力な復旧支援（間違って上書きしても安全区域から即座に復元）**
   - **元通り上書き復元**: 間違って編集・上書きしてしまった元ファイルを、過去の任意バージョンの状態へ一発復元。
   - **デスクトップへ救出**: 元ファイルを残したまま、デスクトップに `[復旧済み]_vX_ファイル名` として安全に救出。
   - **別名・別フォルダー保存**: 任意のディレクトリを指定して復旧可能。

7. **🚨 エクスプローラーからの完全削除にも対応（元ファイル消失検知）**
   - Windowsのエクスプローラー上でゴミ箱も含めて完全削除されても、アプリが「元ファイル消失」を即座に検知し警告バッジを表示。
   - 安全区域に完全な実体コピーが保存されているため、いつでもワンクリックで元通りに復活できます。

8. **🚀 起動時のリアルタイム更新確認＆近未来アニメーション進行バー**
   - アプリ起動時にGitHub最新リリースを瞬時に自動チェック。
   - アップデートが見つかった場合、近未来サイバーパンク調のリアルタイムアニメーション進行バー（速度・進捗率・ダウンロード容量表示）でかっこよくアップデート！

## 💻 動作環境
- **OS**: Windows 10 / 11 (64-bit)
- **Runtime**: Node.js v20+ / Electron

---

## 🛠️ インストール＆ビルド手順

### 開発モード
```powershell
npm install
npm run dev
```

### パッケージ・インストーラーのビルド
```powershell
npm run build
npm run dist
```
ビルドが完了すると `release/` ディレクトリ内にインストーラー (`LocalTimeMachine-Setup-1.0.0.exe`) およびポータブル版が生成されます。

---

## 🔒 セキュリティ＆プライバシー
すべてのスナップショットおよびファイルデータはユーザー自身のパソコン内のローカル安全区域にのみ保管され、外部サーバーへファイル本体が送信されることはありません。
完全なローカルプライバシーを保証します。
